# game-dump/ — recovered game project (NOT in git)

Running `tools/recover.md` (gdre_tools) writes the fully recovered Shotgun King
project into this folder. It is the creator's IP and is **ignored by git** —
never commit, never publish, never share files from here.

This is the *working copy* the Godot editor opens and that `tools/apply.ps1`
copies our `modded/` files over. If a game update or a bad edit wrecks it,
delete the contents and re-run recovery — our real changes all live in `modded/`.
